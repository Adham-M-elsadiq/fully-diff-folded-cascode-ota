# Fully-Differential Folded Cascode OTA Design

This repository contains the design, simulation, and layout files for a Fully-Differential Folded Cascode Operational Transconductance Amplifier (OTA).

## Directory Structure

*   **`docs/`**: Project documentation, hand calculations, design specifications, and reports.
*   **`simulations/`**: Testbenches, spice netlists, and simulation results (e.g., AC, DC, Transient, Noise analysis).
*   **`layout/`**: Layout views (GDSII) and verification reports (DRC, LVS, PEX).
*   **`scripts/`**: Automation scripts (Python, MATLAB, Ocean/SKILL) for data processing or simulation setup.
